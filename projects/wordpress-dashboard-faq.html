WordPress Dashboard FAQ

A short knowledge base entry that anticipates common questions about simplifying a WordPress dashboard.

How do I clean up my WordPress dashboard without editing code?

You can customize the dashboard using Screen Options.

  1. Click Screen Options in the upper-right corner of the dashboard.
  2. Uncheck the dashboard panels you want to hide.
  3. Your changes apply immediately. To restore a panel, check its box again.

What sections can I hide?

Depending on your setup, you may be able to hide panels such as Quick Draft, WordPress News, Activity, and Site Health Status.

Does this affect other users?

No. Screen Options customize the dashboard view for your user account, not everyone on the site.

Can I remove dashboard panels permanently?

More permanent customization is possible with administrative plugins or code changes. For most people, Screen Options is the simplest and most reversible starting point.
